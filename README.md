# tianchi-yang.github.io
Personal academic website

To list a container manuscript, publish the file and add an entry to `container-proofs.json` with its `title`, `date` (YYYY-MM-DD), and `url` (a relative file path or an HTTPS link). The homepage shows the two most recent entries. The Publications page lists all entries in this file.

For a further application, publish the PDF under `papers/` and link to it from `containers.html`.
